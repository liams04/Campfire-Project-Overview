# Screenshots & Permissions Policy

## Confidentiality & Permissions Policy

Because **Campfire Music Foundation** is an active nonprofit startup with unreleased features and private creator agreements, **visual screenshots should only be added to this portfolio with explicit permission from foundation leadership**.

If you have permission to capture and display public-facing UI screens from the application, follow the guidelines below.

---

## Recommended Showcase Screens (If Permitted)

### 1. `01_library_overview.png` — Listener Library Section
* **What to showcase**: The rebuilt Library overview in `apps/web` displaying tabbed navigation between Playlists, Liked Songs, Saved Albums, and Followed Artists.
* **Why**: Visually showcases your primary frontend feature rebuild and responsive layout design.

### 2. `02_audio_player_controls.png` — Player & Liked Songs Controls
* **What to showcase**: The persistent bottom audio playback bar showing track details, the timeline playhead scrubber, and the Liked Songs shuffle/repeat controls.
* **Why**: Demonstrates attention to detail in audio playback UI and your fix for playhead timeline alignment.

### 3. `03_mobile_viewport_gate.png` — Desktop-Only Viewport Gate
* **What to showcase**: The modal / notification surfaced when viewing desktop-optimized flows on a mobile viewport.
* **Why**: Demonstrates defensive responsive UX design and edge-case handling.

---

## Sanitization & Privacy Rules
* **No Unreleased Content**: Ensure audio tracks, artwork, and artist profiles shown in screenshots are either placeholder/mock data or publicly released releases.
* **No Internal Tools**: Never capture or publish views from `apps/admin`, internal analytics consoles, or sensitive financial payout tables.
* **No Secrets**: Never expose staging URLs, test credentials, or internal API headers in browser address bars or developer console drawers.
